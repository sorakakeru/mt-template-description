# mt-template-description

Movable Typeのテンプレートに補足入力欄を追加し、テンプレート一覧に表示させるプラグインです。\
不具合などあれば、Issuesにいただけますと幸いです。

## 設置方法

リポジトリをcloneし、`/TemplateDescription`ディレクトリをMovable Typeの`/plugins`ディレクトリに設置、有効化してください。

## 利用方法

プラグインを有効化すると、テンプレート編集画面に「テンプレート補足文」という欄が表示されます。\
この欄に入力・保存されたテキストは、テンプレート一覧に表示されます。

## 動作環境

ソフトウェア版のMovable Type9最新版にて動作検証済みです。\
MTクラウド等では未検証です。
